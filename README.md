# Md Zubair — Academic Portfolio

Personal academic website inspired by [ffathena.github.io](https://ffathena.github.io/) (Wowchemy Academic layout), with content adapted from [zubair063.github.io](https://zubair063.github.io/).

## Structure

```
Portfolio/
├── index.html
├── css/style.css
├── js/main.js
├── assets/
│   ├── zubair.png
│   └── avatar.jpg
└── README.md
```

## Sections

- **Home** — profile, bio, education, research interests
- **Updates** — recent milestones
- **Experience** — academic, industry, and voluntary roles
- **Certifications** — Coursera / Dataquest credentials
- **Publications** — journal, conference, thesis supervision
- **Articles** — filterable Medium / Towards Data Science writing
- **Projects** — selected GitHub projects
- **Contact**

## Preview locally

```bash
cd Portfolio
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).

## Deploy to GitHub Pages

Push this folder to a repository (or replace the contents of `Zubair063.github.io`) and enable GitHub Pages from the root.
